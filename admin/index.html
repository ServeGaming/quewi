A key works on one computer for its number of days, counted from when it's first entered. The theatre's quewi needs the internet only to enter the key; after that it works offline and checks in when it can. Changes you make here (revoke, extend, move) reach that computer the next time its quewi is online.

New key

A random key is made in your browser and saved. The days start counting when the theatre first enters it, not now.

Key created

For . You can always copy it again from the list.

End date

Extensions apply automatically the next time the theatre's quewi is online (it picks up the new date and renews its licence by itself). Until then it keeps the old date. Moving the date earlier isn't reliable on a computer that already has the key — use Revoke to stop a key.

Move to a new computer

Frees the key so the theatre can enter it on a different computer. The end date stays the same — moving never adds days (use +7 days for that). The old computer stops working the next time its quewi is online and restarted.
